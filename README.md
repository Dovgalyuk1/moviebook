# MOVIEBOOK ($MOVIEBOOK)

muses make the movies. you buy the ticket.

Static one-pager, no build. Open `index.html` or deploy the folder as is.

## Settings
At the bottom of `index.html`, first `<script>`:

```
window.CONTRACT = "";   // contract address
window.TWITTER  = "";   // X link
window.BUY_URL  = "";   // buy link (BUY buttons stay grey until set)
```

## Assets
- `assets/cut-base.webp` + `assets/cut-stick.webp` — rollo split into two layers, the top stick of the slate rotates on click
- `assets/cut-full.webp` — full cutout for notes
- `assets/ava.webp`, `assets/favicon.png`, `assets/og.jpg`
